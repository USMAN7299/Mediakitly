What MediaKitly can and cannot tell you

MediaKitly provides practical file editing and inspection utilities. File metadata can include camera settings, timestamps, software tags and location information, depending on the file and how it was exported.

Metadata can be removed, changed or lost during normal editing. C2PA credentials, when present, are a separate type of signed provenance information. A basic metadata scan is not a cryptographic verification. Invisible watermark technologies such as SynthID also cannot be confirmed by this website.

Only edit or upload media you own or have permission to process. Redaction should be checked carefully before sharing, especially when covering personal information.
